Public site reset launched

The old portal-style landing experience was replaced with a clearer multipage public site. The homepage now explains the work directly, the navigation is live, and the visual system remains atmospheric without hiding what the project actually is.

The site now uses shared styles and a shared interaction script, including the optional sound toggle, hover response, and card glow behavior.

April 2026

The Lumina lane is no longer only long-range language. It now rests on a governed core path that gives the public story a more structural base.

Lumina can now carry project stance through runtime state and emit descriptive status from recorded state in both concise and human-readable form.
