Lumina prototype - built for returning

Come back to the work without losing yourself in the machine.

EthereonLabs is building Lumina: a human-scale workspace for artists, educators, researchers, builders, and teams who carry complicated projects across days, interruptions, tools, and conversations.

See the buildOpen prototype dashboardRead the principles

This is not another glowing AI wrapper. It is a careful experiment in continuity, context, creative return, and visible boundaries.

Field note
“I was in the middle of something. I need the room to remember enough for me to begin again.”

Lumina starts there: not with spectacle, but with the ordinary human problem of returning to meaningful work after life, tabs, classes, meetings, and attention have scattered the thread.

resumeorientcontinue

A workspace should feel like a room you can re-enter.

Most software treats every return like a cold start. EthereonLabs is exploring a different kind of environment: one that remembers the project shape, explains what changed, keeps useful material close, and helps the next step feel possible.

For interrupted people

Teachers between campuses. Artists between studio sessions. Researchers between notes. Builders between tools. Lumina is for people whose work has a long memory.

For complicated projects

Instead of flattening everything into a chat, Lumina treats work as a place: goals, references, decisions, open questions, history, and next actions all have somewhere to live.

For trust

The system should show what it knows, what it does not know, what it is allowed to do, and when a human needs to decide.

How Lumina helps

Less drama. More return.

The public prototype is early, but the direction is clear: make complex work easier to resume without pretending the software is magic.

Prototype surface

The dashboard is a window, not a judge.

Lumina’s dashboard makes system signals visible: continuity state, history, trends, graph, motion, and mood. It displays the project weather so a human can orient more quickly.

Open dashboard

The deeper architecture stays inspectable.

Behind the warmer surface is a disciplined runtime experiment: mode law, session state, input integrity, capability boundaries, sea trials, governance logs, and canon lineage. The poetic layer can inspire the interface, but it does not get to secretly run the machine.

Mode law

Different kinds of work need different permissions: observing, building, testing, and promoting should not collapse into one blurred state.
