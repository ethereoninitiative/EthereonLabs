Prototype phase - work that can return

Software should help you pick up where you left off.

EthereonLabs is building workspaces that remember the shape of a project so artists, educators, builders, researchers, and teams can return without starting over.

See what we are buildingOpen prototype dashboardRead principlesView project map

Lumina is our prototype for helping work return clearly. It keeps track of project state, useful context, and visible system activity. The Realm is the larger map that shows where each part of the work belongs.

In plain terms

We are exploring a software layer that remembers what matters in your work, keeps useful tools and notes close, and helps you return with less friction.

What it is

A prototype for workspaces that preserve context, notes, references, project state, and likely next steps.

Who it is for

People doing long-running creative, technical, educational, research, or design work where context matters.

What exists now

A public website, a Lumina dashboard, early runtime experiments, clear boundaries, and a growing project map.

Prototype surface

Lumina has a public dashboard.

The dashboard shows visible project signals: system mood, continuity state, trends, graph, history, motion, and optional audio. It displays information; it does not make decisions for the user.
