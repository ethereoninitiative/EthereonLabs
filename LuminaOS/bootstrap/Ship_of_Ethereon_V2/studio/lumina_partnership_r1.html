Invite an AI contribution

A compatible AI client can use the existing Lumina command entrypoint. It needs explicit local access; this page does not summon or run a model.

lumina partnership join atelier "Atelier Agent"
lumina partnership board
lumina partnership propose TASK_ID --by atelier --text "My suggestion"

Replace TASK_ID with the task ID shown below each task. Refresh the board to see the proposal. Approval is a recorded decision, not execution.
