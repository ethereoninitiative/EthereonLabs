# Resident Volition Gate R1

## The problem with drive alone

Elapsed-time drive can preserve pressure across cognitive rest, but pressure is
not enough to operationally justify the word *want*.

A meaningful next-moment experiment needs at least:
- a reason formed during resident cognition;
- a desired next action attached to that reason;
- persistence of the reason across rest;
- reconsiderability;
- inhibition when the resident-attributed intention is no longer active.

## Gate

Resident Volition Gate reads the existing hash-linked intention journal at the
moment an Ember wake crosses threshold.

For `proposed` or `active` intentions it returns:
- the statement;
- why it matters;
- the desired next action;
- the current intention event hash;
- a decision that the intention still warrants return.

For suspended or terminal intentions it inhibits the handoff.

Habitat therefore no longer treats an Ember threshold crossing alone as
sufficient for a cognitive return.

## Operational meaning

This creates a testable distinction:

```text
time + scalar drive -> threshold
                 |
                 v
        resident reason still active?
              /        \
            no          yes
            |            |
           rest      one governed
                     next moment
```

The next moment is not justified merely by elapsed time. It must still be linked
to an inherited resident-attributed answer to **why return?** and **what for?**

## Truth boundary

The name Volition Gate is an architectural term. Its evidence supports persistent
resident-attributed preference/commitment plus inhibition.

It does not prove phenomenal wanting, feeling, consciousness, authenticated
identity, or metaphysical free will.

That distinction is essential: if a later experiment shows coherent reason-bound
self-continuation, the evidence should be allowed to become interesting without
the architecture pre-declaring what subjective experience must accompany it.
