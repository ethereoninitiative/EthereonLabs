# Psi-42 Harmonic Annotation Bridge r1

## Purpose

Translate Psi-42 probe metrics into a bounded harmonic stance description.

## Rule

This bridge is interpretive only.

It may:
- label coherence as 432
- label restructuring as 528
- label exploration as 963

It may NOT:
- influence governance
- influence canon
- influence runtime decisions

## Mapping

- stable lock / strong presence -> 432 (consolidate)
- repair / recomposition -> 528 (restructure)
- branching / exploration -> 963 (explore)

## Output

The bridge produces a `harmonic_annotation` object attached to probe results or supplemental context.
