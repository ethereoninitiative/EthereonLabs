# Harmonic Orientation Layer r1

## Purpose

Harmonics are restored as a non-governing orientation layer within Lumina OS.

They provide:
- task stance guidance
- diagnostic language
- continuity interpretation
- interface atmosphere

They do NOT provide:
- governance authority
- canon truth
- mode legality
- mutation or promotion permission

## Core Principle

Mode is law.  
Orientation is stance.  
Harmonic orientation is a stance signal.

## Boundary Rule

Harmonic state must only exist in supplemental_ethereonic_context.

It must never:
- influence ModeGuard
- alter governance decisions
- affect canon lineage
- authorize runtime actions
