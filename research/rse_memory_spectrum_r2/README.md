# RSE Memory Spectrum R2 — 2026-11-25
Exploratory, reproducible, not peer reviewed. Builds on the RSE crystalline work and [observer feedback R1](https://github.com/ethereoninitiative/EthereonLabs/pull/555), but does not depend on its merge.

## Discovery method
Examine what can be recovered from a finite memory trace without assuming that a particular rotation is optimal. Use L=512, real independent unit-variance zero-mean inputs u, normalized weights w(n) proportional to n^(-phi) or q^(n-1). Solve q=.6141664691 so the exponential and power-law scalar filters have equal weight energy .2390295786. Complex rotation corresponds to two real coordinates h_n=w_n(cos(2*pi*alpha*n),sin(2*pi*alpha*n)). Baselines: real power/exponential, exponential with phi rotation, two real exponential traces (matched fast q and chosen slow q=.97). Same lag limit; not matched execution cost. No feedback, nonlinearity or fitted adaptive operator in this R2 experiment.

## Exact identity
Let x=sum_n h_n u_(t-n), covariance C=sum_n h_n h_n^T. Optimal linear prediction of unit-variance u_(t-n) has population R^2_n=h_n^T C^+ h_n (Moore-Penrose inverse). Sum over n = trace(C^+ C)=rank(C). This is a standard projection identity, not a claim of novel general mathematics. The available linear memory is redistributed by geometry rather than multiplied beyond the state rank. This is not a bound on arbitrary nonlinear memory. The rank-one implementation assumes the rank-one vectors in the test cases are collinear; the rank threshold is numerical.

Every rank-two case has total 2 to numerical tolerance. A seeded simulation with 8192 samples validates lag 4 for three cases within absolute tolerance .05; this is a smoke check, not confidence intervals or a train/test benchmark. All eight exact cases passed score and rank-sum assertions. Larger total capacity than a rank-one system simply reflects additional real state dimension. The power-law tail can outperform an energy-matched single exponential at distant lags while losing at other lags; absolute distant-lag recoverability may be tiny.

## Second observation: fragile versus usable dimensions
Add independent isotropic measurement noise with variance v to each real coordinate. C becomes C+vI; covariances with input remain h_n. Total recoverable memory becomes trace((C+vI)^(-1) C)=sum_j lambda_j/(lambda_j+v). Equal total weight energy fixes sum lambda_j but not their distribution. For fixed trace and positive v, concavity of x/(x+v) implies that equal eigenvalues maximize capacity. Hence geometric conditioning is distinct from noise-free rank.

| rotation | smaller eigenvalue | capacity at v=.001 |
|---|---:|---:|
| zero | 0 | .995834 |
| .0001 | .0000001624 | .995996 |
| .01 | .000780906 | 1.434308 |

A nearly zero rotation creates a formally second dimension, but its capacity largely disappears under measurement noise. A rational quarter rotation beats phi on this particular noise metric. Noise is hypothetical and added at readout, not dynamical perturbation. No assertion of optimal phase over all possible values. Different temporal retrieval objectives can prefer different rotations.

## Reproduction and boundaries
Run node memory_spectrum_r2.mjs and node noise_sweep_r2.mjs. No dependencies. JSON receipts were generated by executing the functions in a JavaScript environment prior to commit. Population metrics are computed analytically; only three lag-4 scores are Monte Carlo estimates. These are linear filters, not intelligent residents; no claim about consciousness or quantum measurement. The current comparison has not completed the full R1 predictive benchmark.
