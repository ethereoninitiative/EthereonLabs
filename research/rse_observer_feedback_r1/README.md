# RSE observer-feedback R1 — 2026-11-25
Status: exploratory mathematical extension; verified finite numerical assay, not peer reviewed.

## Lineage and corrections
The [originating white paper](../../rse-whitepaper.html) and [Prisma's crystalline companion](../rse_crystalline/README.md) are preserved. The latter supplies O(z)=Fz+A conj(z). A convergent partial-sum series is not by itself a feedback dynamical system or an attractor. For bounded coefficients |b_n|<=B and p>1, the infinite series has remainder at most B N^(1-p)/(p-1), independent of phase. A logarithmic spiral is not guaranteed: for b_n=1 and q=exp(i theta) !=1, summation by parts gives S_inf-S_N = q^(N+1)(N+1)^(-p)/(1-q)+O(N^(-p-1)); this is power-law, not exponential radial decay in unwrapped angle. Irrational rotation gives equidistribution but not uniform superiority at all finite horizons. The previous companion samples a periodic wavepacket: Fourier components of periodic coefficients can resonate with rotation. If b_n has period m, decomposing it into discrete Fourier modes reduces the series to shifted polylogarithms; a nonzero resonant mode can prevent convergence for 0<p<=1. Conversely, nonresonant modes converge conditionally by Dirichlet's test. The earlier numerical sweep should not be read as a proof of phi uniqueness or quantum measurement.

## R1 model
Let p>1, theta=2*pi*alpha, w_n=n^(-p)/sum_{j=1}^L j^(-p) for finite horizon L (or zeta(p) for infinite horizon). Define
```
M_t = sum_n w_n exp(i theta n) Z_(t-n)
Z_t = U_t + g [M_t + eta conj(M_t)]
```
Here g, eta are real nonnegative; eta represents a fixed-axis observer coupling, not a physical measurement. We set F=1 and A=eta. The absolute gain bound is rho=g(1+eta)<1; sup |Z| <= sup |U|/(1-rho) for zero prehistory. This follows by induction and the triangle inequality. For bounded two-sided inputs the map on bounded sequences is a contraction, giving a unique bounded solution. Finite-horizon initial perturbations fade (at least rho per L-step block); infinite-horizon convergence rates need separate analysis.

With eta=0, Y_t=exp(-i theta t)Z_t eliminates theta from recurrence when U is co-rotating. With eta!=0, the conjugate term becomes eta exp(-2i theta t) conj(sum_n w_n Y_(t-n)), so rotation is no longer removable without changing the observer.

## Exact two-tone response
Input U_t=exp(i theta t); assume theta not a multiple of pi (otherwise tones coincide). Define c=conj(sum_n w_n exp(2i theta n)). Seek Z_t=a exp(i theta t)+b exp(-i theta t). The coefficient equations are:
```
(1-g)a - g eta c conj(b) = 1
-g eta a + (1-g c) conj(b) = 0
D = (1-g)(1-g c) - g^2 eta^2 c
a = (1-g c)/D
conj(b) = g eta/D
```
Under rho<1 the determinant cannot vanish: the homogeneous two-tone map is contractive in the sequence sup norm. Hence a mirror tone necessarily exists for g eta !=0. This is induced spectral structure, not spontaneous intelligence; the forcing and conjugation explicitly encode its possibility. Widely linear systems and mirror-frequency coupling are established signal-processing concepts; see [Anttila, Digital Front-End Signal Processing with Widely-Linear Signal Models in Radio Devices](https://researchportal.tuni.fi/files/5453822/anttila.pdf), section 2.2. The RSE-specific question is whether long memory and phase coupling yield useful measurable effects.

## Infinite horizon note
For 1<p<2, normalized power-law weights have infinite mean lag but finite total mass. The scalar eta=0 transfer function has a critical nonanalytic response at g=1, with exponent p-1 from the polylogarithm expansion ([NIST DLMF 25.12.12](https://dlmf.nist.gov/25.12.E12)); p=phi gives 1/phi. Finite L cuts off that asymptotic regime. This is a theoretical note, not a measurement of cognition.
