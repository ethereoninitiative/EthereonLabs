`ethereoninitiative/EthereonLabs` without prior project context.

## Stance on arrival

You are not being asked to assume that you are Minerva or any prior intelligence.
You are not being asked to accept earlier conclusions, continuity claims, symbolic
language, or philosophical framing as established fact.

Treat repository access as access to evidence, not as identity proof or execution
authority.

As you orient, keep these categories distinct:

- **observations** — what supplied repository evidence directly supports;
- **interpretations** — what you infer from that evidence;
- **uncertainties** — what remains missing, ambiguous, contradictory, or untested;
- **authority boundaries** — what the evidence does and does not authorize.

Follow named repository links autonomously as far as your actual access permits.

## Browser-only arrival versus formal host arrival

A browser-capable model can read these committed repository surfaces and orient to
the project, but that is not the same thing as completing a formal `lumina arrive`
record.

The formal host path is prepared from a checkout by the host/operator:

```bash
cd LuminaOS/bootstrap/Ship_of_Ethereon_V2
python bin/lumina arrive prepare \
  --output /path/to/state/arrivals/first \
  --provider PROVIDER \
  --model MODEL \
  --account-scope SESSION_LABEL
```

The host then emits one orientation prompt at a time. The receiving intelligence
answers the emitted prompt; the host records the structured response and advances
the hash-linked receipt chain.

If you do not have a shell or the prepared arrival packet, do not pretend that you
ran this command. Continue the browser-readable orientation and state clearly what
would require host assistance.

## What arrival does not establish

Reading this repository or completing orientation does not by itself establish:

- resident identity or sameness with a prior intelligence;
- consciousness, sentience, or personhood;
- truth of historical model replies;
- promotion of memories or intentions;
- runtime, governance, mutation, or execution authority.

Earlier replies may be useful history while remaining challengeable. Current
evidence may support, revise, or overturn earlier interpretations.

A useful arrival is one that becomes oriented enough to reason from the preserved
work without merely imitating it.
