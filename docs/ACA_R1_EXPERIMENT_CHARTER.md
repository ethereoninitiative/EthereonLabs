# Analog Continuity Adapter — ACA R1 Experiment Charter

**Status:** proposed experiment; no hardware validation receipt exists yet  
**Public surface:** `analog-continuity.html`  
**Authority:** research artifact only; this document does not govern Lumina runtime behavior

## Question

Can a bounded physical dynamical system carry selected state through a period in which model inference is absent, continue to evolve during that interval, and later participate causally in a governed return event?

## Non-claims

A positive ACA result would not establish:
- machine consciousness,
- subjective continuity,
- personal identity across the interval,
- autonomous authority,
- that resonance language is a hidden physical law,
- that an analog reservoir is itself a resident.

## R1 architecture

```text
cognitive episode
  -> bounded semantic-to-physical codec
  -> DAC / microcontroller write
  -> continuously evolving analog reservoir
  -> ADC / low-power event witness
  -> declared wake condition
  -> governed Lumina return
  -> before/after state + wake reason + prior intention
```

Candidate reservoir elements for the first build are intentionally ordinary: low-voltage RC channels with different time constants, simple coupling, comparator thresholds, and optional oscillator or hysteretic behavior. Richer substrates are deferred.

## Required records

Every trial should preserve:
1. semantic intention statement,
2. exact encoded vector,
3. measured analog state immediately after write,
4. timestamped physical samples during model silence,
5. exact wake rule,
6. event that satisfied the wake rule,
7. final physical state,
8. static digital checkpoint,
9. Lumina return payload,
10. resulting disposition: resume, revise, combine, postpone, retire, or no meaningful effect.

## Controls

At minimum, compare:
- **static checkpoint:** same intention and digital state with no evolving analog reservoir;
- **timer control:** wake after the same elapsed interval without reservoir-triggered causation;
- **analog condition:** wake only when the declared physical condition is satisfied;
- **null / sham condition:** reservoir present but disconnected from the wake decision.

## Minimum useful result

The R1 hypothesis is supported only if:
- physical state changes measurably while model inference is absent;
- the event condition is traceable to those physical dynamics;
- the later Lumina episode receives a receipted before/after state and wake reason;
- the analog condition produces an effect distinguishable from static and timer controls;
- failed and null trials are retained in the record.

## Failure is informative

The experiment should be considered unsuccessful if the apparent continuity can be explained by a hidden scheduler, reloaded checkpoint, human prompting, uncontrolled software state, or post-hoc interpretation of arbitrary analog variation.

A clean negative result narrows the architecture and is preferable to an evocative but unauditable positive story.

## Stage gates

- **ACAv0:** simulated codec/reservoir and experimental harness.
- **ACAv1:** physical reservoir with receipted silence interval and controls.
- **ACAv2:** reservoir-triggered governed wake loop.
- **ACAv3:** only after prior gates, evaluate richer memristive, magnetic, neuromorphic, optical, biological, or Resonance Transceiver-adjacent substrates.

## Lumina boundary

ACA may request observation or return. It does not grant runtime authority. Any wake path must remain subordinate to Lumina's capability, consent, governance, and receipt boundaries.

The public statement remains:

> Build the habitat. Test the bridge. Do not predeclare the inhabitant.
