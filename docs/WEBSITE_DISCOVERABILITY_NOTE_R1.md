# Website Discoverability Note R1

**Status:** implementation note  
**Scope:** public navigation and discoverability; not runtime authority

The `how-lumina-works.html` page is a primary public explanation of the governed runtime and continuity substrate.

It must remain discoverable from every ordinary website page through a persistent header action and the secondary footer links. Page-specific hero links are useful but are not sufficient as the sole discovery path.

This navigation surface communicates architecture only. It does not define runtime law, authorize action, promote canon, or create continuity truth.
