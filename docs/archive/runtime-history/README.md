# Runtime History Archive

This lane preserves superseded executable experiments that helped shape the current Lumina runtime but no longer own an active execution path.

## Lumina daemon v0.1

`lumina-daemon-v0_1/` preserves the early resident heartbeat/daemon experiment, its smoke test, and its original contract. The implementation is retained for lineage and comparison only.

The current governed runtime lives under:

- `LuminaOS/bootstrap/Ship_of_Ethereon_V2/`

Current resident pulse behavior is separately governed and validated in the active V2 runtime lane. The archived daemon must not be treated as a parallel resident service or current authority.
