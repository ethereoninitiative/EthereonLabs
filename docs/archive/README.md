# Documentation Archive

This directory preserves superseded implementation records, completed dry-dock material, and other historical artifacts whose lineage remains useful but whose placement beside active contracts would create present-tense ambiguity.

## Archive rule

Archived material is evidence of project history. It is **not** an active runtime entrypoint, governance contract, capability declaration, canon authority, deployment truth, or current operator instruction unless a current active document explicitly says otherwise.

Git history remains the complete provenance record. This archive exists to preserve useful evolutionary information while keeping active repository surfaces legible.

## Pruning principle

> No unique idea disappears merely because its implementation is obsolete.

Current architecture stays in current lanes. Historical implementations move here when retaining them in active-looking locations would obscure ownership or truth.
