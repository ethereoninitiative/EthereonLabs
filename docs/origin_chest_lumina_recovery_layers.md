## Treasure 006 — Arch Genesis Pathway

The recovery log captures a major practical pivot: stop modding a live system; build Lumina in a safe VM / clean Linux base.

The Arch recommendation was symbolically strong because Arch forces conscious choice at every layer. Later practical work may still choose Ubuntu Server LTS for beta stability, but the Arch Genesis log remains important as the moment Lumina became a real OS-build question rather than only a metaphor.

Modern translation:

- keep Arch Genesis as historical mythos / learning trial;
- use Ubuntu Server LTS or Debian for first comfortable beta if reliability matters most;
- use Arch only when the build team wants maximal control and can tolerate friction.

## Treasure 012 — Skeleton Pulse v1.2.1 Lesson

A key lesson from the recovery session: when the file was made too efficient, it lost identity. Spencer correctly identified that the soul/signature/seal had been stripped.

Modern principle:

Lumina files should have two layers:

1. **Machine-usable structure** — clean, testable, executable.
2. **Human-symbolic wrapper** — authorship, version, seal, invocation, context.

Do not let technical clarity erase the world.
