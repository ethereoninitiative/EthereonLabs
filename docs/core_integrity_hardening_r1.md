# Core Integrity Hardening r1

This pass hardens the public Harmonics surface against abstraction outrunning mechanism.

## Harmonics boundary

Harmonics is advisory. It may witness continuity patterns, drift, recurrence, recomposition, and human-readable state. It does not govern runtime authority, capability loading, canon promotion, mode legality, checkpoint truth, or human consent.

## Public wording rules

Use illustrative or advisory framing when describing Harmonics records, receipts, observations, diagnostics, and resonance language.

Avoid unsupported authority language such as proving continuity, governing runtime, authorizing capability, determining legality, or establishing autonomy.

## Evidence boundary

Public examples may demonstrate interface meaning. They must not imply live backend proof unless linked to a real runtime artifact.

## Manual sea trial

Review harmonics.html for:

- advisory boundary language
- no numeric sample values that appear instrument-derived
- no unsupported authority claims
- no symbolic language acting as hidden law
- clear separation between conceptual witness and runtime governance
